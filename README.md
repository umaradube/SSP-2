# Super Sound Studio Pro

Complete, custom-coded static website. No website builder, installation, build step, API key or paid package is required. All images are included locally.

## Preview
Extract the entire ZIP, then open `index.html` in a modern browser. Keep `assets`, `styles.css` and `script.js` alongside it. For a local web server, run `python -m http.server 8080` inside this folder and visit http://localhost:8080.

## Upload
Upload the contents of this folder to any static website host. `index.html` must be at the root of the publish directory. For Netlify manual deployment, drag this extracted folder into the deployment area. No build command is needed. This ZIP does not publish or change an existing website.

## Included
- Navy, red and white theme.
- Original supplied circular logo displayed using an SVG viewport of the original artwork, with no redrawing.
- Supplied promotional imagery displayed using SVG viewports; original files retained unchanged in assets.
- Editorial five-column desktop gallery; two-column mobile layout.
- Staggered image changes, scroll parallax, image hover transitions, entrance and scroll reveals.
- Pause-motion control and reduced-motion preference support.
- Responsive service sections, photography pricing, event information and contact details.
- Keyboard-accessible service menu, visible focus states and labelled fields.
- WhatsApp enquiry composer, direct telephone and email links.

## Design reference and limits
The implementation follows the visual structure observed at vivmgmt.com: minimal navigation, large brand presentation, staggered image columns, image transitions, editorial statement, service grid and typographic footer. It is an original implementation adapted to the supplied company content and imagery, not the reference site's source code or an exact pixel-for-pixel copy. The supplied artwork is static, so no original event video is implied. Detail crops from the lower-resolution advert photographs retain their original resolution.
